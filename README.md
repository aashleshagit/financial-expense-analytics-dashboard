# financial-expense-analytics-dashboard

## Overview

This project is an interactive financial analytics dashboard developed using Python, Excel, and Power BI. It helps users analyze income, expenses, savings, and spending patterns through visual reports.

## Tools Used

* Python
* Pandas
* Excel
* Power BI

## Features

* Income Tracking
* Expense Tracking
* Savings Calculation
* Expense Distribution Analysis
* Monthly Expense Trends
* Interactive Filters
* Financial Insights Dashboard

## Project Results

* Total Income: ₹25,000
* Total Expenses: ₹11,985
* Total Savings: ₹13,015
